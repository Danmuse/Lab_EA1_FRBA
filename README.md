## 📕️ __Overview__

The **Single-stage amplifiers** project involves the design, simulation, and experimental validation of single-stage amplifier circuits using bipolar junction transistors (BJTs) and field-effect transistors (FETs). The main objective is to compare theoretical small-signal and biasing calculations with actual laboratory measurements.
